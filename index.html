¿Qué es Docker?

Docker es una plataforma que permite ejecutar aplicaciones dentro de contenedores. Estos incluyen los elementos que necesita una aplicación para funcionar, como sus bibliotecas y dependencias.

¿Qué es un contenedor?

Es un entorno aislado donde se ejecuta una aplicación. Ayuda a que funcione de manera similar en diferentes ordenadores y servidores.

¿Qué es una imagen?

Es una plantilla que contiene lo necesario para crear un contenedor.

Ventajas de Docker

1. Portabilidad

Permite ejecutar aplicaciones en diferentes equipos que tengan Docker instalado y sean compatibles.

2. Consistencia

Ayuda a mantener un entorno parecido durante el desarrollo, las pruebas y la ejecución de una aplicación.

3. Aislamiento

Las aplicaciones pueden ejecutarse en contenedores separados, con sus propias dependencias.

4. Facilidad para desplegar

Facilita distribuir aplicaciones y ponerlas en marcha sin tener que configurar manualmente cada dependencia.

Comandos básicos

docker --version

Muestra la versión instalada de Docker.

docker pull nginx

Descarga la imagen de Nginx.

docker images

Muestra las imágenes descargadas.

docker run hello-world

Ejecuta un contenedor de prueba.

docker ps

Muestra los contenedores en ejecución.

docker ps -a

Muestra todos los contenedores, incluidos los detenidos.

docker stop nombre_contenedor

Detiene un contenedor en ejecución.

Ejemplo práctico

Este comando inicia un servidor web Nginx:

docker run --name mi-web -d -p 8080:80 nginx

Significado de las partes:

  • run: crea e inicia un contenedor.
  • --name mi-web: asigna el nombre mi-web.
  • -d: ejecuta el contenedor en segundo plano.
  • -p 8080:80: conecta el puerto 8080 del ordenador con el puerto 80 del contenedor.
  • nginx: indica la imagen que se utilizará.

Después, abre http://localhost:8080 en el navegador.

Docker Compose

Docker Compose permite definir y ejecutar varios servicios mediante un archivo de configuración llamado compose.yaml.

Ejemplo de compose.yaml

services:
    web:
        image: nginx:alpine
        ports:
        - "8080:80"
        restart: unless-stopped

¿Qué significa cada parte?

services:

Declara los servicios que formarán parte de la aplicación.

web:

Es el nombre que le damos al servicio. Podría llamarse también servidor, aplicacion u otro nombre.

image: nginx:alpine

Indica que se utilizará la imagen de Nginx con la variante Alpine.

ports:

Permite conectar puertos del ordenador con los del contenedor. En "8080:80", el 8080 es el puerto del ordenador y el 80 es el del contenedor.

restart: unless-stopped

Hace que Docker reinicie el contenedor automáticamente, salvo que se haya detenido manualmente.

Comandos de Docker Compose

docker compose up -d

Crea e inicia los servicios en segundo plano.

docker compose ps

Muestra el estado de los servicios.

docker compose logs -f

Muestra los registros de los servicios.

docker compose down

Detiene y elimina los contenedores y la red creados por Compose. Normalmente conserva los volúmenes.

¿Cómo probar el ejemplo?

  1. Crea una carpeta para el proyecto.
  2. Guarda el código en un archivo llamado compose.yaml.
  3. Abre una terminal dentro de esa carpeta.
  4. Ejecuta docker compose up -d.
  5. Visita http://localhost:8080
  6. Cuando termines, ejecuta docker compose down.

Instalación

Docker puede instalarse mediante Docker Desktop o Docker Engine, según el sistema operativo.

Ventajas

Los contenedores ayudan a mantener entornos consistentes y facilitan la distribución de aplicaciones.

Extensiones y herramientas

Puedes utilizar Docker Compose para gestionar aplicaciones compuestas por varios servicios.
